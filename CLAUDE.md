# Claude Code Pointer

Read `AGENTS.md` and treat it as the canonical repository-wide instructions.

Before non-trivial engineering work, also read `AGENT_WORKFLOW.md` and follow
its freshness, investigation, review, and evidence requirements. These are the
same shared instructions used by Codex. Read the actual files; do not rely on
a previous session's summary. Follow applicable nested instructions as well.

Project hooks are supplementary: verify tool availability, synchronization
success, and the current checkout before trusting graph results. A configured
hook is not evidence that it ran. If required instructions or tools cannot be
loaded, report the specific limitation and continue only work that does not
depend on them.
