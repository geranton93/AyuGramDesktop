## API credentials

Official Telegram keys:

API_ID `YOUR_API_ID`

API_HASH `YOUR_API_HASH`

Create your own application at [my.telegram.org](https://my.telegram.org),
then pass these values to CMake as `TDESKTOP_API_ID` and `TDESKTOP_API_HASH`.
Do not commit personal credentials or place them in a tracked configuration
file.
